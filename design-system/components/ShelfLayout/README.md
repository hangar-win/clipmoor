The horizontal Shelf (Raf), up to 920×260: search, type tabs and pin-group pills on one row, and the ShelfCards below. Cards keep the width five of them take at 920px (seven when compact). The window narrows to its content: the wider of the header row and the cards shown, never below `panel-w`. Past 920px the cards scroll sideways. While open, a width change keeps the window's horizontal centre.

←/→ move the selection. Ctrl+1…9 paste a card. The window takes the same `radius-window` and `frame` ring as the panel.
