The Settings window: about 900×640, resizable, with a Windows 11 style rail on the left and a 576px content column.

**Sections.** Genel, Kısayollar, Görünüm, Geçmiş, Güvenlik. Görünüm (shown) holds the mode, layout and density segments, the PaletteCards and the ColorEditor. Page padding is `space-28` / `space-32`. The title is `settings-title`. Section captions are `settings-caption` in `text-muted` and upper-case.
