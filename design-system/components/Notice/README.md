The inline notice in both windows. It is an outlined box with no fill.

**Anatomy.** `control` text in `text`, padded `space-8` / `space-12`, 1px `frame`, `radius-control`, and an optional 12px icon (`triangle-alert`). The Settings notice now matches (it used to have a muted fill).

**Use** for one sentence that explains a state and the way out. Don't use it for errors under a field (use the ShortcutField error line) or for success toasts (there are none).
