One Settings row: a label with an optional hint on the left, the control on the right.

**Anatomy.** Min height 57, padding `space-12`, a `space-24` gap, and a 1px `settings-border` divider. The label uses `settings-body`. The hint uses `settings-hint` in `settings-text-muted`, `space-2` below. Controls sit `space-8` apart. Use `.is-stacked` for wide controls (ColorEditor, palettes). The small reset Button sits last, at `opacity-idle` when the value is already the default.
