A selectable card for one ready-made palette (or "Özel" for custom colours) in Settings › Görünüm.

**Anatomy.** 152px wide, padded `space-8`, 1px `settings-field`, `radius-card`. A 72px mini preview is split into the palette's dark and light halves, each drawn from that palette's own `ground`, `card`, `hairline`, `text-muted`, three hue bands and the selection ring. The name is in `settings-body`. Selected: a 2px `settings-text` edge, `settings-body-strong`, and a check icon. Özel: a dashed preview edge and a pencil icon; selecting it opens ColorEditor.

**Palettes.** Grafit (default), Gri, Haki gri, Gece, Kum. Only Grafit has values yet; the other four render once their values land in `tokens.dtcg.json`.
