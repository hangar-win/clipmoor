The type filter: Tümü, Metin, Resim, Link, Renk, Kod. Each type tab has an 8px colour key.

**Anatomy.** Tabs `space-4` apart, padded `space-4` / `space-9`, `radius-control`, `title` in `text-muted`. The key is `tab-key` with `radius-dot` in the type hue. Renk's key is the spectrum conic gradient. Tümü has no key.

**States.** Hover: `strip`. Active: `active` block, 1px `active-edge`, `title-strong`, `text-on-active`. Inactive tabs keep a transparent 1px border so the size never shifts.

**Where.** In List and Compact, the filter row (behind Tab, under the search). In Shelf, inline on the header row. In Palette, Tab cycles the type filter shown as a pill in the search.
