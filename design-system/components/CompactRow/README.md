A single-line, 36px item row for compact density: content on the left, time on the right.

**Use** when Görünüm › Yoğunluk is "Kompakt", mostly with the List layout.

**Anatomy.** A `band-slim-w` band, then `body`/`code` content (ellipsis) and the time in `control` `text-muted` with optional 12px pin/lock icons. Height is `compact-row-h`. Inline padding is `space-12`.

**States.** Like ListCard: hover `strip`, selected ring plus `selection-edge`.

**Consumer provides** type, content, time, and flags. Section headers still apply between groups.
